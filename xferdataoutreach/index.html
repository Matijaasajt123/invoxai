Overview & Architecture

The system connects three platforms into one pipeline. Each tool does one job only — outreach, orchestration, or relationship tracking — and hands its output to the next stage automatically. Nothing about a lead's status is stored twice, and nothing needs to be re-entered by hand. The pipeline's job ends where the human conversation begins: a booked call.

02

How the System Works

Three connected mechanisms carry data through the pipeline. Each one triggers the next — nothing runs on a fixed schedule waiting for someone to check it.

A

LinkedIn messaging & reply capture

HeyReach runs the outbound sequence — connection request, follow-up messages, and any conditional branches — directly against the target list. When a prospect replies, HeyReach flags that conversation and stops the remaining sequence steps for that person, so no further automated messages go out once a human is engaged.

Sequence sent Reply detected Sequence paused
B

N8N → HubSpot handoff

N8N listens for that reply event, pulls the prospect's details from HeyReach, and writes them into HubSpot. It creates the contact record if one doesn't already exist, and opens a new deal on the pipeline so the conversation is immediately visible to the sales side of the CRM — no manual copy-paste between tools.

Event trigger Contact created Deal opened
C

Reply statistics & campaign testing

Every sequence is measured by how many prospects actually reply. That reply data is tracked per campaign inside HubSpot, so it's clear which messaging, targeting, or sequence structure is performing better than another. Those numbers are what we use to test and refine campaigns going forward — decisions are based on what the data shows, not on guesswork.

What We Need From You

Building this pipeline requires access to the platforms involved, and one small piece of tracking code placed on your side. Nothing here requires you to build anything — only to grant access and place a snippet where your team can reach it.

⚿

HubSpot access

  • Login or API access to the CRM where contacts and deals will live
  • Permission to configure the pipeline stages the workflow writes into
⚿

HeyReach access

  • Login or API access to the account running LinkedIn sequences
  • Visibility into the target lists and sequences already in use
⚿

N8N workspace access

  • Access to the workspace where the connecting workflows are built and run
  • Any existing credentials already configured for HubSpot
⚿

Tracking snippet placement

  • A short webhook/tracking snippet added to the landing page
  • The same snippet added at app log-in, placed by your developer or team
NOTE — access is used only to configure and connect the workflow described above. Any credentials shared can be scoped or rotated according to your own security policy.
